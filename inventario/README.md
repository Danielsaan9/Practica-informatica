# GLPI Fundación Luz

Paquete completo de la aplicación web GLPI 12.0.1 trabajada para Fundación Luz.

- Código GLPI y personalizaciones: `app/glpi/`
- Directorio web que debe servir Apache: `app/glpi/public/`
- Plugin Fundación Luz: `app/glpi/plugins/fundacionluz/`
- Instalador local para un destino vacío: `scripts/instalar-local.ps1`
- Recursos gráficos originales: `assets/brand/`

El repositorio contiene código; no contiene la base de datos, `config/`, `config_stage/`, `files/`, tokens, claves de cifrado ni credenciales. Configuración y datos se preparan localmente. Mantén los avisos de licencia y autoría de GLPI y sus dependencias.

Las guías personales de instalación y funcionamiento se entregan por separado, fuera de este repositorio.
